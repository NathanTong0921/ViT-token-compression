# 2026-10-27：Flowers102 定向复现

## 问题与结论

按 [预测前固定的方案](../flowers-targeted-validation.md)，检验 Pets 的 49／98-token 条件化收益差异及 H2 能否在另一数据集重现。选择这两个预算受已知 Pets 结果启发，范围在 Flowers 预测产生前确定；Pets 147 的结果继续保留。

**H2 在两个预算上复现；条件化在 Flowers 的 98-token 上获得小幅准确率收益，但 Pets 的负／正预算模式没有复现。** Flowers 两个预算的平均间隔收益都为正，98 减 49 的收益差区间跨零。结果支持有条件的学习收益和跨数据集的几何关联，没有支持普遍最优的预算。

## 执行设计

官方训练、验证各 1,020 张，每类各十张；6,149 张测试图片未用于模型训练或预测。由官方类别缩略图编号匹配名称与标签，102 个类别的对应关系与图片数均通过核对。固定平衡任务图包含训练 612 对、验证 204 对，另留测试 204 对。验证组合中有 4,080 个图片／任务样本及 6,120 个同图任务对。

冻结 CLIP ViT-B/16，block 6 后保留 49 或 98 个 patch，并保留 CLS。两个预算使用相同的图片、类别组合、轻量 selector 结构、KL 目标、优化器和种子。每预算独立生成 512-mask ridge 教师，条件化／图像版各训练三个模型，均使用 3,978 次更新的最终权重。对应的任务／类别侧呈现次数恰好为 416。训练图片数与 Pets 不同，训练步数与 Pets 相差 0.3%；跨数据集比较不能识别单一因素的因果影响。

主指标按任务与类别等权，先平均三个固定种子，再对图片聚类 bootstrap 2,000 次。两个预算的每项主指标分别使用 97.5% 调整区间。预先指定的直接间隔对比 `D98−D49` 使用普通 95% 区间。H2 沿用连续二次难度控制、图片固定效应与五折留出图片预测。

代码与方案在实质运行前提交。原始来源版本、全部命令、环境及时间保存在 [执行记录](../../results/flowers-selector-budgets-v1/execution/pipeline_status.json)。服务器目录为 `/data2/zhao.tong/experiments`，使用 physical GPU 4 的一张 RTX A6000。九个阶段全部成功，未因结果更换种子、超参数、检查点或重跑模型。

## 结果与核验

| 指标 | 49 tokens | 98 tokens |
| --- | ---: | ---: |
| 条件化 − 图像版：准确率（百分点） | +0.2288 [−0.1879, +0.6209] | +0.2778 [+0.0082, +0.5474] |
| 条件化 − 图像版：间隔 | +0.001178 [+0.000427, +0.001964] | +0.001363 [+0.000870, +0.001800] |
| H2 斜率／10° | +0.001469 [+0.001141, +0.001790] | +0.001491 [+0.001266, +0.001719] |

表内为 97.5% 调整区间。直接间隔对比为 +0.000185，95% 区间 [−0.000540, +0.000861]。H2 的图片内分析和六个逐种子斜率同向，留出图片 ΔR² 为 0.0212 与 0.0464；它们是控制当前难度变量后的预测关联。

全部 2,040 张训练／验证图的原始 CLIP 与保留全部 token 特征完全相同。28 项相关服务器测试通过。独立复算使用原始 102 类分数重建分类结果、主区间和预算对比，再独立拟合 H2 系数及检查折外预测指标，全部一致。H2 的完整 bootstrap 未重复执行，其调整方式、秩与决策一致性已检查。见 [科学核验](../../results/flowers-selector-budgets-v1/scientific_audit.json)。

十二次模型训练全部正常完成。条件化版验证 KL 更高而实际分类间隔更好，是对 I2／I3／I6 中“代理指标与选择效用不同”的延伸；它没有单独证明过拟合或数据量造成了分类结果。

完整方法表、逐种子结果、交换效应、图表和解释见 [结果说明](../../results/flowers-selector-budgets-v1/README.md)。
