# Two versus five candidate classes

## Question

Does increasing the number of candidate classes change the benefit of task-conditioned token selection over a comparable-capacity image-only selector?

This development extension uses Pets and Flowers, frozen CLIP ViT-B/16, pruning after block 6, and 98 retained patches. It compares conditioned C and strong image-only U with seeds 2041–2043. Full CLIP and attention selection are reference points. The existing reserved binary test remains a separate completed experiment.

## Candidate tasks

Use the existing training and validation image partitions. For each dataset, shuffle the class order with seed 2611 and draw six cyclic offsets. Four offsets define training tasks and two define validation tasks. For each offset and each starting class, form a set of two or five consecutive offset positions. Every member class contributes labeled examples; every class occurs equally often within each task size and split. Candidate sets are unordered, and validation sets differ from training sets. Two- and five-class tasks share the shuffled class order and offsets.

Each task has equal evaluation weight, its member classes have equal weight, and images are averaged within each class. Training samples uniformly across task/class slots and available class images. The C and U arms use identical examples and update counts for each seed. Two- and five-class comparisons use the same number of updates and all available training images.

## Selector and supervision

The candidate descriptor concatenates the mean text embedding and twice its population standard deviation. With two classes, this equals the existing mean-plus-absolute-difference descriptor. The conditioned architecture and the wider image-only architecture retain their previous hidden dimensions (128 and 199).

For each saved probe mask, define the task margin as the minimum normalized true-versus-competitor score difference over the candidate set. Fit this scalar response to the existing mask bank using the same ridge projector. Standardize its patch coefficients and apply softmax to obtain the training target. For a binary task this reduces to the existing geometric-margin target; five-class targets account for changes in the closest decision boundary across probe masks. Targets use training labels; the selector receives only image tokens and the unordered candidate text set.

Reuse the saved 512-mask responses and frozen prefixes; no new backbone training or mask-probe inference is needed. Train with the previous AdamW settings and fixed update counts: 3990 for Pets and 3978 for Flowers. Use the final update for every run.

## Measurements

Report full and compressed accuracy, true-class minus strongest-competitor score, normalized geometric margin, and errors added or repaired relative to full CLIP. The main contrasts are C−U within each dataset/task size and the change in C−U from two to five classes. Average the three seeds, then bootstrap paired images with all their tasks kept together. Also exchange task-conditioned selections between tasks on the same image, keeping the classification task fixed.

The extension does not add a multiclass H2 angle definition. Its purpose is to evaluate task-set size within the existing research question. Results will be interpreted as development evidence; any later final confirmation will use fixed choices from this extension.
