# Patch Ranking 外部对照

问题：本项目的强共享选择与独立来源的 preservation predictor 相比表现如何？将排序教师、预测器恢复率和最终分类放在一起，解释差异产生的环节。

## 本轮设置

- 冻结 OpenAI CLIP ViT-B/16，在 block6 后保留98/196个patch；Pets和Flowers沿用既有训练／开发图片、文本与任务划分。
- 教师采用论文描述的2×2滑动删除，按覆盖次数平均 cosine drop；删除发生在与选择器相同的位置。已有前半模型特征直接复用。
- 预测器采用公开实现的通道池化、一个MixerBlock和评分头，共46,246参数。公开KL目标等权保留前146个排序位置，降低最后50个位置的权重。
- 按公开入口用Adam、50 epochs、初始学习率0.001、cosine降至0.0001、weight decay0.0001、batch64。保存最终模型，三个种子2041／2042／2043。
- 主要比较为PR减强共享U、PR减条件化C；同时列原共享、attention、random、完整CLIP及离线preservation教师。使用既有任务／类别权重，主区间沿用图片配对重采样，四个主要比较分别在各指标内调整。
- 记录教师集合恢复率@98、@100和删除50个的恢复率；附全类别分类表现、参数量和实际运行成本。运行成本与部署延迟分别记录。

这是本项目设定下的Patch Ranking适配：剪枝位置、任务面板和训练图片沿用当前研究，教师按论文滑动窗口描述，预测器与目标按公开代码。具体来源和实现差异见[方法核对](../patch-ranking-implementation.md)。最终预留测试留在选定方法的开发比较完成后。

对应proposal H3与强共享比较的延伸。小规模流程和四项模型／目标检查通过后，完成两个数据集共六次50-epoch训练、分类评价与完整在线延迟测量。[结果与原始记录](../../results/patch-ranking-v1/README.md)。

## 结果

PR适配版相对强共享U的准确率差为Pets −0.339pp、Flowers −0.662pp；相对C为−0.365pp、−0.866pp。四项调整区间均低于零。离线preservation教师本身的准确率为97.915%／96.054%，也低于U和C，因此差距不只取决于小预测器是否学准教师。

RTX A6000空闲窗口测量中，batch32的PR完整推理为19.26／19.33ms，U为19.58／19.63ms；batch1没有稳定速度优势。46,246参数预测器的体积优势主要体现在选择器本身，完整图像网络有86.19M参数。

训练和教师生成沿用cached block6；计时重新执行完整图像前向。服务器统计完成后在本地生成图，避免服务器增加绘图依赖。分类表与种子平均、主要差值经过独立数值核对。全部六个权重与删除响应归档，候选类别preservation目标留作下一研究决策。
