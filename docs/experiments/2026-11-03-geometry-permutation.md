# 2026-11-03：图内任务对应与归一化对齐

## 与 proposal 的联系

这是 H2 的最后一项有边界的开发阶段补强。此前交换损失的分解表明，文本方向夹角直接出现在公式中；归一化对齐分析去掉了显式角度和位移长度因子。本轮进一步检验：真实任务对应下的对齐—角度关系，是否超过保持图像和特征集合不变的随机对应参考。用户确认先做此项，再固定最终测试方案。

## 固定方案与执行

[协议](../geometry-permutation.md)先于打乱结果提交，覆盖已有全部七个 H2 设置：Pets ViT-B/16 的 49／98／147 patch，Flowers102 ViT-B/16 的 49／98，以及两个数据集 ViT-L/14 的 128。复用 KL 条件化模型的三个固定种子 2041／2042／2043，没有新训练、教师生成或图像推理。

对每张图的全部任务对，保留任务方向、未压缩几何分类间隔和角度，把已经保存的选择后特征重新分配给任务。完整任务图保证图内特征差异长度的多重集合不变。1,999 次独立分配由种子 2094 生成；同一数据集／图片／任务集合在各设置中使用相同映射。

主分析取三个种子的特征均值，不再次归一化，复现已有 H2 观测值后才计算参考分布。主统计量为控制未压缩间隔及对称二次项后，对齐对角度的斜率，每张图片等权，角度单位为 10°。七项主比较统一 Bonferroni 调整；图片固定效应和平均对齐作为描述性补充。

## 结果

七个主统计量均为正，并且均高于全部 1,999 次参考：原始参考尾值 0.0005，七项调整后 0.0035。逐种子的 21 个观测斜率也均为正。完整数字、图表与解释见[结果汇总](../../results/geometry-permutation-v1/README.md)。

这为已有几何关联补上任务对应层面的证据：去掉公式中的显式角度项后，真实对应依然产生比图内打乱更强的对齐—角度关系。它加强 H2 的研究深度，不改变此前条件化与强共享图像基线的分类收益结论。预留测试尚未使用，下一步固定最终独立确认方案。

## 数据与实现核对

- Pets：616 张可构成任务对的开发图片、2,524 个图片—任务行、4,315 对；Flowers102：1,020 张图片、4,080 行、6,120 对。各设置的同数据集面板一致。
- 最初输入准备在辅助逐种子摘要处停止：Pets49 seed 2042 的 `havanese_151` 有一对零位移特征，余弦未定义。此时尚未生成任何打乱结果。辅助摘要按已有几何定义只使用有定义的对齐，并记录这一对；主分析的种子均值全部有效，主总体和统计量未修改。停止记录保存在 execution/input_attempt。
- 正式分析和独立复核使用代码版本 `4493f0b4f0b13903a3b4f1804eb34ebc3862ba2c`。独立实现不导入新增核心分析模块，从原始预测和划分文件重建面板，复算所有设置的全部参考，核对逐种子摘要、任务方向、间隔、几何恒等式、任务对长度多重集合和共享映射。七项均通过，参考统计最大绝对差小于 1e-15。
- 服务器相关测试 194 项通过；本地针对本轮的 21 项测试通过。代码测试、实际输入复现和独立数值核对分别覆盖实现与真实数据。
