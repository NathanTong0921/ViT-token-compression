# 2026-10-27：三种 token 预算与 H2 几何分析

## 本轮解决的问题

上一轮扩大训练图片覆盖后，49-token 条件化 selector 的教师拟合改善，但其分类准确率没有稳定超过图像版，平均间隔反而略低。本轮按 [预先固定的协议](../selector-budgets-h2.md)完成 49／98／147-token 比较，检验这一差距是否依赖压缩程度，并完成 proposal H2 的难度调整分析。

结论是：**预算会改变条件化间隔收益的方向；文本分隔方向夹角在原始难度之外仍有预测作用，但两者都尚未转化成普遍准确率领先。** 这为“何时需要任务信息”提供了更具体的回答。

## 固定设计与执行

冻结 CLIP ViT-B/16，在 block 6 后保留 49、98、147／196 个 patch；使用全部 2,944 张训练图和 532 个训练组合。每预算条件化／图像版各三个 seed（2041、2042、2043），模型均为 348,033 参数、hidden width 128。固定 3,990 更新、batch 128、AdamW 学习率 0.0003、weight decay 0.01，使用 KL 软重要性监督与最终步权重。不同预算共享相同采样流，每任务／类别各呈现 480 次。

49-token 的六个完整覆盖模型及既有预测直接复用；98／147 各生成完整 3,680 张训练／开发图的预算匹配监督（512 masks、ridge 0.01），再各训练六个模型。因此本轮新增 12 个权重，三预算合计比较 18 个。随机选择使用固定 seed 2055／2056／2057，各图片排序跨预算不变，保留集合嵌套。未更换 seed、训练目标或超参数。

736 张开发图全部参与评估。主要未见组合面板为 66 个任务、716 张图、2,624 行；已见组合为 532 个任务、736 张图、21,162 行。最终 3,669 张测试图及 68 个任务未使用。主效应为每预算的条件化 − 图像版准确率及有符号几何间隔；任务／类别等权，固定 seed 先平均，图片聚类 bootstrap 2,000 次。对三个预算分别报告普通 95% 及 Bonferroni 98.333% 区间。

服务器为 `/data2/zhao.tong/experiments`，使用一张 RTX A6000（physical GPU 4）。主流程代码与共享诊断代码均在运行前提交，来源版本及逐阶段命令保存在 [主流程记录](../../results/pets-selector-budgets-v1/execution/pets-selector-budgets-pipeline-v1/pipeline_status.json) 和 [共享诊断记录](../../results/pets-selector-budgets-v1/execution/pets-selector-budgets-shared-pipeline-v1/pipeline_status.json)。

## 任务交换、H2 与数学分解

三个预算使用同一个交换面板：616 张图片、4,315 个图片／任务对；每对先平均三个 seed，每张图片等权。正确任务描述相对交换描述的平均间隔收益分别为 0.001795、0.001154、0.000335，普通 95% 区间均为正；准确率交换效应均不明确。选择集合重合率从 76.54% 增至 86.44%、91.37%；图像版交换效应严格为零。

H2 控制两个未压缩有符号间隔的较小值、较大值、各自平方及乘积，再加入夹角项。以下斜率按每 10° 计，区间对三个预算调整：

| 保留 token | 每增加 10° 的调整后交换损失斜率 | 三预算调整后区间（98.333%） | 留出图片预测的 ΔR²（95% 区间） |
| --- | ---: | ---: | ---: |
| 49 | +0.000971 | [+0.000711, +0.001258] | +0.0240 [+0.0127, +0.0359] |
| 98 | +0.000462 | [+0.000286, +0.000634] | +0.0114 [+0.0038, +0.0206] |
| 147 | +0.000171 | [+0.000083, +0.000261] | +0.0062 [+0.0006, +0.0126] |

图片固定效应斜率分别为 0.001255、0.000731、0.000180，普通 95% 区间均为正；九个逐 seed 斜率也均为正。五折划分以图片为单位，预处理和拟合仅用训练折，加入角度后的 ΔR² 为 0.0240、0.0114、0.0062。这个增量有限，验证范围仍是固定开发任务集合上的留出图片，不能写成新任务上的回归泛化。

对称交换损失满足 `L = 0.5 (z_A−z_B)·(u_A−u_B) = ||z_A−z_B|| sin(θ/2) cos(φ)`。这个恒等式明确了原始关联中固有的角度因子，不能单独作为机制贡献。探索性对齐分析中，`cos(φ)` 的难度调整斜率在三个预算仍为正（0.012743、0.007772、0.005252／10°），图片固定效应方向一致；两个预定小位移阈值都没有排除样本。它提示原始关系不只包含显式角度尺度变化，但不构成因果识别。平均损失的对齐分解来自 seed 平均特征位移，不是部署集成方法。见 [完整几何分析](../../results/pets-selector-budgets-v1/geometry/analysis.json)。

## 强共享离线诊断

每个交换样本都用相同的 524 条目库比较分别搜索与共享搜索：512 个探测 mask，加两个任务教师、一个 attention、三个图像版、六个条件化候选。两种搜索都知道标签和任务；共享搜索最大化两任务的平均几何间隔，候选可重复。分别优化的间隔不劣于共享优化是定义保证的，不将其正差值当作可部署收益或全局最优证据。

| 保留 token | 分别搜索 − 共享搜索：间隔（95% 区间） | 离线教师 − 共享搜索：间隔（95% 区间） | 库内存在同时答对两任务的共享选择 |
| --- | ---: | ---: | ---: |
| 49 | +0.006182 [+0.005866, +0.006481] | -0.004338 [-0.005225, -0.003445] | 99.9459% |
| 98 | +0.006406 [+0.006066, +0.006719] | +0.001673 [+0.000779, +0.002564] | 99.9459% |
| 147 | +0.006893 [+0.006607, +0.007181] | +0.005527 [+0.004926, +0.006092] | 99.8918% |

库内通常能找到一个同时答对两任务的共享选择，显示分类正确性已接近饱和，专用选择更多影响间隔。49-token 离线教师的间隔低于共同库中的共享最优选择，98／147 则较高；这进一步说明教师质量、共享搜索强度和学习到的效果需要分别衡量。目标最优的共享选择与是否存在同时答对两任务的选择已分开统计。

为统一证据可用性，单独重新计算 49-token 旧面板 144 张图的 73,728 个 mask 响应，重拟合系数／截距与原缓存误差均为零；未覆盖旧教师或预测。该补充保存在独立文件。新 524 条目库与早期 192 候选 pilot 不直接等同。

## 对 proposal 的影响及下一步

H1 获得了更完整的任务依赖证据，同时共同库说明共享选择通常也能同时分类正确。H2 在控制难度、图片固定效应和留出图片预测上获得一致的开发集支持。H3 得到预算相关的部分支持：98-token 学到间隔收益并推广至未见类别组合，但准确率优势仍未建立；49／147 的结果限制了适用范围。

本轮对研究目标是正面推进，增加的是有依据的适用条件和解释，并未把混合结果改写成全面成功。下一步按已确认的 scope 完成 Flowers102 和 ViT-L/14 定向验证，以及完整推理开销测量；在验证方案固定后才使用最终测试集确认。监督目标与保留判别信息的关系可以成为新的受控延伸，需单独立实验并完整保留结果。
