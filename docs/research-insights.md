# 研究洞见与后续判断

本文件集中保存实验过程中形成的认识，供后续设计实验、写 report 和准备讲解时查阅。每次实验的配置、完整结果和复现步骤仍保存在 [experiments/](experiments/)；这里记录“发现了什么、证据在哪里、改变了什么判断”。

更新日期：2026-10-18。当前证据来自冻结 CLIP ViT-B/16、block 6 剪枝、Oxford Pets 开发集上的离线实验。尚未训练跨图片的 selector。

## I1：估计 token 重要性时的压缩程度，会影响最终选择的质量

**状态：在当前强压缩设置中获得受控实验支持。**

- **从哪里来：**上一轮局部删除排序在保留 49/196 个 patch 时只有 93.37% 准确率，低于 attention 的 97.92%。这促使我们检验：接近完整图片时估计出的重要性，是否适合大量删除 token？
- **证据：**固定同一种 ridge 估计方法和 512 次探测，将估计上下文从保留 192 个 patch 改为 49 个，144 张开发图片上的平衡二分类准确率从 94.89% 提高到 100%；对独立随机集合的 margin 预测相关性从 0.253 提高到 0.657。第二套探测种子在同一 36 张子集上保留了这一趋势。详见 [主实验结果](../results/pets-budget-ranking-v1/README.md) 和 [配对统计](../results/pets-budget-ranking-v1/comparison.json)。
- **可以得出的认识：**在这套估计方法下，重要性评估的上下文是影响强压缩选择质量的一个因素。这个对照支持采用目标预算下生成的监督。
- **仍需区分：**这些任务排序使用真实标签；100% 是离线诊断结果。保留 147 个 patch 时没有明确的 margin 增益，不能概括成“预算匹配始终更好”。两组探测次数相同，但计算耗时不同。
- **对项目的影响：**这是 proposal 中“离线排序与监督生成”的延伸，起点是上一轮的强压缩失效。下一步先在 49 patch 下检验监督能否被轻量 selector 学到；跨数据集或模型的普适性留待后续验证。

## I2：选中的 token 集合可以不同，而观察到的任务表现接近

**状态：已观察到现象；对训练方式的含义仍待实验验证。**

- **从哪里来：**为复核 I1，我们更换了随机探测种子，并保留相同图片、任务和其他设置。
- **证据：**在 36 张图片、49 patch 的预算匹配实验中，两套选择的平均重合率为 46.3%（交集大小除以 49）；两次平衡准确率均为 100%，图片等权平均 margin 约为 0.14599 和 0.14639。具体定义与配对区间见 [种子稳定性数据](../results/pets-budget-ranking-replication-v1/seed_stability.json)。
- **可以得出的认识：**在这批样本上，明显不同的集合也能取得接近的观察结果。精确重现某一个离线集合，不适合作为学习成功的唯一标准。
- **尚未解决：**这可能涉及多组有效证据、估计噪声或当前任务的准确率饱和，现有实验不能区分这些解释。平均差值的区间包含零，也不等于证明两种选择在统计上等效。
- **对项目的影响：**这是监督生成复核带来的新观察，关联 H3。训练后应以实际分类表现和 margin 为主要判断，集合重合率只作诊断。是否改用软排序目标或多种监督集合，仍是后续可检验的想法，尚未证明能改善训练。

## I3：预测随机 token 集合的能力，与选出好集合的能力需要分别衡量

**状态：在当前 98 patch 设置中观察到两种指标的不同变化。**

- **证据：**在 144 张图片、保留 98 个 patch 时，预算匹配使独立随机集合的预测相关性从 0.614 降到 0.593，中心化 MSE 也略差；但实际执行 top-k 后，平衡准确率从 98.48% 提高到 99.81%，平均 margin 也提高。见 [配对预测与选择结果](../results/pets-budget-ranking-v1/comparison.json)。
- **可以得出的认识：**对普通随机集合预测更准，并不必然意味着优化得到的 top-k 更好。两项评估应同时保留。
- **尚未解决：**优化出的集合可能与随机探测集合有不同的分布，但当前结果没有单独验证这一解释，也没有证明 token 交互是原因。
- **对项目的影响：**这是 I1 的受控比较中产生的新观察。后续选择监督方法、评估 selector 时，都应实际运行压缩后的模型，不能仅凭拟合误差或排序一致性判断效果。

## 原研究问题目前走到哪里

上述发现改善了研究工具和监督质量，但不能替代 3B 的核心比较。当前预算匹配排序存在任务专用性：交换选择会损失 margin，也优于简单的两任务平均排序；但共同候选库中的强共享搜索仍可达到相同准确率，并获得更高平均 margin。

因此，**H1 的专用性证据加强，超过强共享选择的优势尚未建立；H2 仍是探索性分析；H3 尚未检验。** 下一步是同容量、同训练数据与监督分布的条件化／图像专用 selector 试训，检验候选类别信息是否带来可学习、可泛化的收益。

## 如何持续更新

- 有实质新发现时，更新相应条目或新增条目，并链接实验记录与原始结果。普通运行进度留在实验记录里。
- 后续证据若支持、限制或推翻某条认识，更新状态并追加带日期的说明，保留最初判断与改变原因。
- 写最终 report 时，从这些条目中选择证据充分、与主问题相关的内容；“值得继续研究”与“已形成论文贡献”分别判断。
