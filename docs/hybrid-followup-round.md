# 混合选择的任务价值与可学习性（2026-11-04）

用户授权并行推进两条研究：共享与条件化选择的互补是否超出普通多模型互补，以及此前混合选择能否被一个小模型学到。两条独立执行，不以第一条出现正结果作为启动第二条的条件。全部使用现有训练／开发数据，正式测试保持预留。

## A：条件化＋共享，与两个共享比较

沿用Pets49／98、Flowers49／98，冻结已有三个种子2041–2043的条件化C和加宽共享U。混合规则固定为此前matched-replacement的50%规则：保留交集，从接收方独有位置中删去低排名的一半，再补入供给方独有位置中的高排名token，总k不变。

主要比较使用全部六个有序异种子对s≠t：C_s接收U_t，与U_s接收U_t直接比较。两侧都运行两个选择器，总参数约相同；不把同种子C_s＋U_s与异种子U_s＋U_t的差异混入主要比较。同种子混合仅保留为先前结果参照。

主要结果为margin与准确率的直接差，四设置分别做图片配对bootstrap及四比较区间调整。先在同一图片内平均种子对，不把同一图片的六个种子对当作独立样本。保留所有种子对、端点表现、实际替换数与集合分歧大小。

另报告辅助交互`(CU−C_s)−(UU−U_s)`，区分接收方原本表现与混合新增收益。这一交互不替代最终CU−UU性能比较，不增加模型推理。

辅助干预固定实际替换d=2或4，仅在两种混合均有足够独有位置的行上比较，记录覆盖率与受限评估对象。共享混合规则不读取C的当前任务输出来决定其替换数。固定d结果用于解释实际改动量，主要性能比较仍使用完整面板的固定50%规则。

## B：直接学习已有混合选择

沿用上一轮Pets49、Flowers49、Flowers98三个设置，冻结相同共享基座U，零输出初始化的任务／图像修正分支分别新增9,801／9,850参数。所有训练种子、图像任务流、更新数、优化器与学习率不变，共18次新拟合。

每个种子的训练目标来自冻结C_s和U_s按上述50%规则得到的mask。两分支都接收相同目标：被选位置赋概率1/k，其余为0，继续使用原softmax KL损失。变化是监督分布，不是另换损失函数。生成选择只使用图片和全部候选类别；真实标签不参与混合规则。

旧18次原监督修正作为2×2对照的一侧，读取其原始预测而不重训。新方法主要比较为任务修正减图像修正在三个设置的分类margin与准确率；报告三比较调整区间。监督改变带来的条件化收益交互为预定的辅助分析，同时给出逐种子结果与配对区间。

记录训练／验证对混合mask的拟合、原监督损失、实际分类与正确／交换任务描述差异。混合教师在验证集上的选择必须复现已保存的top_50；同时保留教师、共享基座和条件化端点，区分教师本身的收益与学生实现的收益。验证目标仅用于诊断，最终固定步检查点用于比较。

两类目标的熵不同，跨目标KL绝对值不用于宣称拟合改善；统一观察mask吻合度与实际分类。同一目标内比较训练／验证损失。辅助保留图像学生相对U、旧图像修正、混合教师的差异，以检验任务信息是否主要有助于构造监督、而收益可由不读取任务的学生保留；不把差异不显著写成性能等效。

## 判断与交付

A回答混合收益是否包含超出两个共享选择器的任务价值；B回答更直接的混合监督是否改善可学习性。更好的训练拟合、正的任务交换效应、超过同预算图像对照，是不同的观测量，分别报告。

本轮主要使用缓存前缀和同图同mask嵌入。计时记录监督构建、新训练和后缀评估；这些重放计时不作为完整推理加速结论。保存原始选择、预测、权重、图表源数据与协议；本地／服务器／GitHub备份验证后清理传输中间文件。

对应proposal H1与H3，由共享互补和上一轮残差泛化差距延伸。运行前提交本协议及代码；结果出来后更新研究洞见与下一步，不以增加实验数量作为贡献判断。
