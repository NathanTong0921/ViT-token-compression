## 1. 已完成：检验训练图片覆盖是否限制泛化

- [x] 固定配对比较方案：592 张与 2,944 张训练图片，均为 3,990 步；采用相同任务／类别分布并重训小数据对照。见 [实验方案](selector-data-coverage.md)。
- [x] 控制架构、监督生成方式、任务分布和优化步数；两种 selector 各保留三个配对种子。明确区分“看到更多不同图片”和“训练更久”。
- [x] 同时记录教师拟合、实际分类准确率、分类间隔、压缩新增错误以及正确／交换任务描述的差异。
- [x] 扩大开发评估到现有 736 张验证图片，统一对照口径；明确新增评估图片随后也属于开发数据。未见组合实际覆盖 716 张，其中旧面板 144 张、新增 572 张。
- [x] 根据结果决定是否需要一个有针对性的训练修正：本轮先保留现有训练路线完成预算比较，不以拟合改善为由增加训练轮数或复杂度；监督目标与实际分类之间的差距列为待解释问题。

结果：条件化验证 KL 从 0.833 降至 0.499，但完整覆盖时相对图像版准确率仅差 +0.0013 个百分点，区间跨零；平均 margin 更低。任务描述交换仍有正向 margin 效应。形成 I6，未建立相对强共享模型的稳定优势。

对应 proposal：H3、配对训练与组合泛化。新增动机：I4 的训练／验证拟合差距，以及 I5 的有用任务信息尚未转化为稳定的共享基线优势。
