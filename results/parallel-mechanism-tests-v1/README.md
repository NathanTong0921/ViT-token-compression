# 三条机制检验：同图熟悉度交换、等替换量、几何匹配

**本轮最明确的新证据来自 Flowers 的熟悉度交换：同一图片、同一候选答案、同一套身份编码下，真实语义相对身份编码的收益会随训练类别角色改变。** 另外两线保留了 margin 层面的互补与取舍，但削弱了原先对共享排名、准确率必要性的解释。

## 2：改变训练熟悉度，固定评估图片与任务

两组类别 H0／H1 在两次训练中交换见过／未见角色；其余类别保持训练可见。两套身份编码均固定不变。评估的类别对从两次训练中排除，沿用相同验证图片，两个候选的熟悉度同时交换。Pets 为49-token，Flowers为98-token，分别沿用上一轮设置。

| 真实文本相对身份编码：见过减未见的配对变化 | Pets | Flowers |
|---|---:|---:|
| 准确率，百分点，95%区间 | −0.068［−0.250，0.107］ | **+0.534［0.103，0.988］** |
| Geometric margin，95%区间 | +0.000439［−0.000314，0.001147］ | **+0.001766［0.000936，0.002614］** |

Flowers三个训练种子的准确率变化均为正。原未见H0变成见过后，真实文本相对身份编码的准确率效应从−0.234变为−0.044pp；原见过H1变成未见后，从+1.096降为+0.219pp。因此支持的是同图任务上的收益变化，不是每次训练里所有见过类别都优于所有未见类别，也不是优势完全随角色翻转。

相对加宽共享模型的对应变化为+0.556pp，区间触及零；margin区间也跨零。本轮更强的证据在于**真实语义与稳定身份信息的区别**。Pets没有得到对应支持。[完整结果与独立核查](../familiarity-switch-v1/README.md)

## 3：删除完全相同的token，补入同样数量

保留条件化集合C与强共享集合U的交集，从C独有部分删除相同位置；只比较从U独有部分按高排名或随机补入。随机候选来自U\\C，不是任意图像位置。四个设置、三个训练种子、两档内部替换比例共八个主要margin比较，经八项比较调整后的区间均包含零。

**混合收益仍然存在。** Flowers49的50%混合方案相对原条件化与强共享的margin分别提高+0.001851和+0.001856，三个种子均为正；但同一候选池内部，高排名相对随机补入仅为−0.000006。Flowers98的50%混合也在普通区间下高于两个端点，尚未建立准确率提升。

这把“共享候选能补充条件化选择”与“必须优先补入共享排名最高的位置”分开了。402,240个选择集合的实际增删位置核对通过，24个历史端点的mask与得分完全一致。[完整结果](../matched-replacement-v1/README.md)

## 1：同图匹配任务角度与完整模型难度

原val类别对的匹配覆盖不足，故在查看新压缩结果前扩大到预先划分的train+val开发类别对，保留同一批合成图及原阈值。完整模型正确的匹配面板为Pets64图、Flowers54图。使用35个固定mask，两层位置完全一致。

49-token下两数据集、两剪枝层的全部匹配图，在同对象和不同对象任务上均找到共同正确mask。16-token仅block6各出现1例不同对象的库内冲突。较强的“不同对象普遍需要不同选择才能答对”设想未得到支持。

匹配后，不同对象的margin取舍仍较大，49-token四设置差值为+0.00664至+0.01043，区间均为正。取舍量本身非负由定义保证；经验结果是匹配后的对象差异。它说明分别提高判别余量与同时答对是不同要求。[扩大面板](../geometry-matched-conflict-devpool-v1/README.md)；[原val面板](../geometry-matched-conflict-v1/README.md)

## 对proposal与下一步的意义

- **H3：**熟悉度干预把已知类组合泛化与新类别语义迁移进一步分开，是本轮最值得继续发展的解释线。
- **H1／H3延伸：**共享候选与条件化选择可以互补，但内部排名的附加价值不明确。可继续研究如何用单个选择器实现互补，而非直接把两模型干预写成加速方法。
- **H1延伸：**几何匹配支持置信余量取舍，未支持广泛的准确率必要性；当前不据此追加合成任务训练。

总体推进是正面的：增加了一项训练干预支持的条件性发现，修正了另外两项解释。原结果及全部固定种子保留，最终测试尚未使用。
