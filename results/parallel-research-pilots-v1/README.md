## 最值得追踪的新发现

Flowers混合类别对：真实文本相对两套身份置换平均，真实类别已知时准确率+0.512pp，真实类别未见时−0.300pp；两侧差异−0.813pp，配对图片95%区间[−1.244,−0.421]。同一方向在原始面板存在，六个种子—映射配对中已知侧收益一致；Pets没有重现。下一步应固定新的类别留出划分，检验该差异是否随类别的训练熟悉度改变。这里尚未建立“偏向熟悉类别”的因果解释。

Flowers49的混合选择比两个端点margin约高0.0017；Flowers98的50%共享核心也提高margin。下一步固定实际替换token数量，区分共享排名价值与仅仅改动较少。当前混合调用两个已有selector，尚不是新的效率方法。

方向1本轮不支持原定深度机制，暂不直接追加学习器训练。若继续，先在构造任务时匹配文本方向几何，再检验紧预算／多任务共同满足。

## 运行与验证

18项新增首轮测试（5+4+9）和3项补充测试通过，覆盖训练／任务隔离、正确分类字典、paired sampling、固定预算及真实后半段的模拟集成。核心保护的24个setting/seed/endpoint与历史开发评估精确一致。两数据集保留全部既定训练种子及身份映射。

三条线的计时阶段合计约0.407小时，其中48次训练及其初始验证约1284秒。它是各阶段计时相加，不是整轮开发耗时或独占GPU小时；数据准备、未计时验证、分析及备份另计，见 `experiment_costs.json`。

对项目的推进为正面：得到更具体、可被下一轮干预验证的泛化不对称与选择互补；第一条较强的机制猜想未得到支持。这些首轮结果还未形成普遍准确率提升。
