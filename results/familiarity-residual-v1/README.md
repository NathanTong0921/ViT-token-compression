# 2026-11-04：熟悉度复现与共享修正

本轮完成方向2／3，共96个新selector和18个小型修正分支。**分析证据增强；新方法尚未超过同等额外图像容量。** 核心问题仍是：候选类别信息什么时候帮助选择视觉证据，以及其作用能否转化为超出强共享选择的收益。

## 方向2：熟悉度改变候选偏好，在Flowers新划分上复现

固定同一评估图片和候选任务，交换两组类别是否出现在selector训练中；真实类别文本与两套固定身份编码分别从头配对训练，保留加宽图像基线。2099为历史探索划分，2100／2101为事先固定的两份新划分。

| 两份新划分平均 | 真实文本相对身份编码：新熟悉类别选择频率变化 | 连续候选方向margin变化 |
|---|---:|---:|
| Pets49 | +0.088pp [−0.105, +0.272] | +0.000926 [+0.000435, +0.001448] |
| Flowers98 | +0.646pp [+0.371, +0.948] | +0.002774 [+0.002156, +0.003395] |

Flowers两个划分的三个训练种子均为正；Pets的预测频率变化不稳定。这里的频率是模型更容易选中哪个候选，**不是整体准确率涨点**。此前seen−held角色统计与候选偏好存在逐例代数等价；本轮按这个含义修正解释，原数字全部保留。

Flowers两类真实图片的分数都朝新熟悉类别移动。五折跨图片估计的全局加性偏移，能消除一部分频率变化，但仅解释约0.6–1.9%的逐行分数变化，普通准确率没有统一改善。部分划分也出现类别分离变化，因此不能把全部作用解释为候选偏移。真实文本相对强共享模型的平均方向margin变化，在Flowers新增划分中接近零。

## 方向3：小型任务修正尚未转化混合选择的优势

冻结现有强共享selector，两种修正都从零输出开始：任务分支新增9,801参数，图像分支新增9,850参数。采用相同原KL目标、训练流与更新数，在Pets49、Flowers49、Flowers98各训练三个种子。

| 设置 | 任务修正−图像修正：margin | 调整后95%区间 | 准确率差 |
|---|---:|---:|---:|
| Pets49 | −0.000141 | [−0.000455, +0.000160] | −0.0020pp |
| Flowers49 | −0.000405 | [−0.000684, −0.000098] | +0.1144pp |
| Flowers98 | −0.000116 | [−0.000331, +0.000078] | −0.0163pp |

三个准确率差的调整区间均跨零。三设置中正确任务描述均比交换描述保留更大margin；任务分支确实使用了任务信息，却没有胜过相同额外预算的图像处理。Flowers49任务分支margin高于原共享基座，但图像分支提高更多。

任务分支的训练KL更低，验证KL却更高；Flowers49为0.1995／0.6534，图像分支为0.2819／0.5821。这为下一步提供了具体目标：检验监督方式能否把已有混合选择优势传递到未见图片与任务。

## 对proposal的推进与下一项

两条线都来自H3“条件化优势能否学到并泛化”，分别延伸此前语义／身份对照和共享／条件化选择互补。前者把单一类别划分现象扩展为新划分复现，并澄清测量的是候选偏好；后者检验了一条实际方法路线，表明只换成残差结构尚不够。

建议下一项固定此前50%混合选择规则，直接用其mask监督任务／图像两种修正，与已完成的原KL构成2×2对照。同步比较混合mask拟合、训练／验证差距及实际分类表现。若两臂都改善，收益主要来自监督；若同一混合监督下任务臂最终超过图像臂，才形成方法层面的任务优势。这是研究建议，本轮未执行新监督训练。

96次新selector纯训练计时2,560.72秒，18次修正计时237.85秒，共**0.777 GPU-hours**。这仅是冻结缓存上的新拟合，不包括之前的CLIP／监督生成、基础共享模型、新特征缓存、分类重放、CPU分析和排队，不是全项目算力消耗。详见`cost_summary.json`。
