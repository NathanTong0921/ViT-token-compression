# 重新审视研究方向：三项低成本诊断

用户要求在不加入 ImageNet 的前提下更大胆地扩展研究。本轮核查已有模型和记录，形成可以进一步检验的具体线索。没有新训练，没有使用正式测试；新任务、类别编码干预和新模型仍处于[设计阶段](../../docs/research-expansion.md)。

## 1．固定上下文的名义参数可以精确折叠

原图像版把任务描述替换为常量c，因此第一层可写成：

`W_image x + W_context LN(c) + b = W_image x + b_effective`。

其348,033个名义参数对应的输入依赖函数，可由宽度相同、214,913参数的图像MLP表示；差额133,120，占38.25%。Pets49与Flowers98各三个已训练检查点、各32张固定开发图片上，float64分数最大误差小于8e-15，保留token集合完全一致。见[逐检查点核对](capacity_folding.json)。

这解释了为什么原“同架构去掉任务输入”对照与后来“把参数转回图像宽度”对照回答不同问题。原对照有效，但名义参数相等不保证输入依赖的表示能力相等。此折叠不能应用于有变化任务输入的条件化模型，也不声称折叠前后重新训练的优化过程相同。

## 2．均值本身保留了已知类别对的身份

设类别文本矩阵T的每行是一类文本向量，若T行满秩，则二类均值满足：

`mean(T[a], T[b]) @ pinv(T) = 0.5 * (e_a + e_b)`。

| 数据集 | 文本字典秩 | 条件数 | 原始均值恢复类别对 |
| --- | ---: | ---: | ---: |
| Pets | 37 / 37 | 24.73 | 666 / 666 |
| Flowers102 | 102 / 102 | 69.29 | 5,151 / 5,151 |

这只读取训练缓存里的文本字典，枚举类别对是代数核查，没有评估正式测试任务。它说明mean-only并不必然丢失候选类别身份，不能直接把mean解释成粗语义、difference解释成独有的类别区别信息。线性代数关系不是新定理，也不证明实际selector采用这种解码。见[完整诊断](descriptor_identity.json)。下一步用真实文本与固定身份编码的配对训练区分语义和身份的作用。

## 3．教师认为变差的选择，实际CLIP有时反而改善

从已有KL／ranking逐例结果重算，使用原任务／类别均衡权重，先平均三个种子。教师预测变化由两目标下的additive utility regret之差得到，共同最优值与截距消去。单位为几何分类间隔。

| 设置／模型 | 教师预测的KL→ranking变化 | 实际CLIP变化 |
| --- | ---: | ---: |
| Pets49 条件化 | −0.004448 | +0.002336 |
| Pets49 原图像版 | −0.009417 | −0.000476 |
| Flowers98 条件化 | −0.005871 | −0.003180 |
| Flowers98 原图像版 | −0.005589 | −0.002368 |

四设置、两种模型的教师utility都随ranking降低，实际变化并不一致。这些是探索性点估计，尚未证明失准的来源。它们支持进一步检查：在随机mask上拟合的教师，对结构化选择的预测是否仍然准确。这里使用的是原图像版，并非后来加宽版。全部四设置、逐种子和两模型交互见[JSON](teacher_transfer/analysis.json)和[48行汇总](teacher_transfer/teacher_transfer.csv)。

同时修正一个解释：AdamW对整体梯度的正比例缩放近似不敏感，所以此前记录的初始梯度范数差异，不能单独解释实际更新强弱。

## 对项目的意义与复现

三项诊断提供了参数、任务编码和监督三个具体切口；它们还不是完整的新机制结论。更大胆的主攻候选是任务证据冲突与信息共享、语义／身份及新类别泛化、共享核心与任务补充。它们均延伸原proposal关于任务信息价值与可学习性的研究，见[完整方案](../../docs/research-expansion.md)。

运行入口：`scripts/diagnose_capacity_folding.py`、`scripts/diagnose_descriptor_identity.py`、`scripts/diagnose_teacher_transfer.py`。三个输出均记录实际代码版本与来源，输入来自既有服务器运行及先前已归档结果。本轮小型结果直接保存在Git，不新增大文件归档。
